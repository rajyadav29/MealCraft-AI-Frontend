# MealCraft AI - Frontend

This is the frontend of **MealCraft AI**, a frontend web application that helps users discover recipes through an easy-to-use interface. The project was built as part of a team project using React and Vite. I mainly worked on the frontend, focusing on building responsive UI components and improving the user experience.

## Features

- Responsive user interface
- AI recipe generation interface
- User authentication
- Multi-language support
- Clean and modern design
- Fast loading with Vite

## Tech Stack

- React
- Vite
- Tailwind CSS
- JavaScript
- React Router
- Axios

## Getting Started

Clone the repository:

```bash
git clone https://github.com/rajyadav29/MealCraft-AI-Frontend.git
```

Go to the project folder:

```bash
cd MealCraft-AI-Frontend
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

The application will run at:

```
http://localhost:5173
```
